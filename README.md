# 📌 Overview

**Quaz (Quantum EEG Signal Classifier)** is a full-stack application designed to analyze EEG (Electroencephalography) recordings using a hybrid machine-learning pipeline that combines classical signal processing with a **Variational Quantum Circuit (VQC)** classifier.

The system processes EEG recordings, extracts relevant signal features, performs dimensionality reduction, and passes the resulting feature representation through a trained quantum machine-learning model.

The project consists of:

- A **React + Vite** frontend
- A **FastAPI** backend
- EEG signal preprocessing
- Feature extraction
- PCA-based dimensionality reduction
- A Variational Quantum Circuit (VQC)
- Model and preprocessing artifacts
- REST API endpoints
- Docker Compose deployment

---

# 🎯 Project Goal

The primary goal of Quaz is to explore how **quantum machine learning** can be applied to EEG signal classification.

The pipeline is designed to transform raw EEG recordings into a compact feature representation that can be processed by a quantum classifier.
